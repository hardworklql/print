##### 注意力机制： 模型在处理信息时关注关键信息，而忽略不相关信息，从而提高信息处理的效率
备注：通过计算语句中所有词汇的相关性，识别出重点词汇，着重关注重点词汇的信息，来理解整条语句的含义。  

##### rag：RAG 包含三个主要过程：检索、增强和生成。检索：根据用户的查询内容，从外部知识库获取相关信息。增强：将用户的查询内容和检索到的相关知识一起嵌入到一个预设的提示词模板中。生成：将经过检索增强的提示词内容输入到大型语言模型中，以生成所需的输出。
备注：RAG就是外加了一个知识库，与外挂一个数据库还不太一样，数据库是存储的基础数据，知识库其实类似于在数据的基础上抽象了一层，类似于用户画像，懂得相关的知识点。

##### MCP：一种通信协议，将大模型和外部其他服务、数据、工具等联通起来。
